## What does this software do?

As you'll read in my professional self assessment, my interest in developing code stems from a desire to creatively problem solve. In my opinion, all software solves a problem.
Pair this interest with my current role as BA for the Supply Chain portion of my company, it seemed perfect to me to create an inventory system.
The original code took a static text file of goods sold in a day and applied some file reading and output manipulation. It was early in the degree and taught me plenty.
I wanted a more dynamic piece of software that solved the problem of having real time access and analytics of inventory. It's certainly an upgrade from v1 to v2 more than a completely different program.

The new software immediately displays pre canned, and business requested, analytics. The user then inputs sales as they happen. As items are input into the program a call goes out to find the current days cost for that item.
The local database stores all of this and auto applies a date stamp so queries can be date based. 

The program is live and active as well as lightweight and uncomplicated for the end user.
